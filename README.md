# 🛒 ShopMart – Modern eCommerce Platform

**ShopMart** is a modern, full-featured eCommerce web application built with **Next.js 15**, **React 19**, and **Tailwind CSS 4**.  
It provides a fast, responsive, and scalable online shopping experience with a clean and modular architecture.

---

## 🚀 Features

- ⚡ **Next.js 15 (Turbopack)** – blazing fast dev and build times  
- 🧭 **Radix UI components** – accessible, headless design primitives  
- 🌀 **Embla Carousel** – smooth product sliders with autoplay support  
- 🔒 **NextAuth.js** – secure user authentication and session handling  
- 🧾 **React Hook Form + Zod** – advanced form handling and validation  
- 🎨 **Tailwind CSS 4** – modern styling with utility-first CSS  
- 🔔 **React Hot Toast** – beautiful toast notifications  
- 🧹 **ESLint + TypeScript** – maintainable, type-safe, clean codebase
